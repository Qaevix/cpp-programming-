## Language Contents

### Natural and Algorithmic Language Elements

- Natural and algorithmic language elements;
	Characters = language alphabet
	Phrases = Expressions
	Sentenses = Operators

### Basic Terms

- **Alphabet** => Language symbols
- **Lexeme** => A minimal meaningful unit of a language
- **Expression** => Defines value calculation
- **Operators** => Define action to be performed
- **Syntax** => Rules that define the combinations of symbols that are consired to be correct
- **Semantics** => Define language elements meaning.
